## Description
Site vitrine complet pour AfriConnect Summit 2026, conférence tech panafricaine fictive. Le site présente l'événement, le programme sur 3 jours, les intervenants et un formulaire d'inscription.

## Technologies utilisées
- HTML5 : Structure sémantique, accessibilité
- CSS3 : Variables CSS, Flexbox, Grid, Media Queries, Dark Mode
- JavaScript Vanilla : DOM, Events, localStorage, IntersectionObserver
- Git & GitHub Pages pour le déploiement

## Fonctionnalités JavaScript implémentées
1. Dark/Light Mode avec toggle dans la navbar et sauvegarde localStorage
2. Compte à rebours temps réel jours/heures/minutes/secondes
3. Onglets Programme pour afficher Jour 1, Jour 2, Jour 3 sans rechargement
4. Filtrage dynamique des intervenants par thématique
5. Validation formulaire Contact avec retour visuel par champ
6. Navbar dynamique au scroll + Menu hamburger mobile
7. Animations fade-in au scroll via IntersectionObserver
8. Bouton retour en haut + Année dynamique dans le footer
